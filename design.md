LUMUS STUDIO — design.md

1. Direção visual

A Lumus deve parecer uma mistura de:

editorial de moda;

galeria de fotografia;

campanha de marca;

filme;

portfolio de direção criativa;

estúdio visual premium.

O projeto NÃO deve ter aparência de:

template de fotógrafo;

landing page SaaS;

site criado por IA;

agência genérica;

site de casamento tradicional;

template corporativo.

2. Filosofia visual

A interface não compete com as fotografias.

A fotografia é o elemento dominante.

O design é construído por:

escala;

fotografia;

ritmo;

espaço;

tipografia;

movimento;

contraste;

alinhamento.

Evitar decoração gratuita.

6. Grid

Desktop:

grid de 12 colunas;

margens laterais entre 32px e 64px;

grandes áreas de espaço negativo;

evitar centralização excessiva.

Tablet:

8 colunas.

Mobile:

4 colunas;

padding horizontal 18–24px.

7. Espaçamento

O projeto deve respirar.

Usar intervalos maiores que um site institucional comum.

Desktop:

section spacing: 140–240px;

pequenas separações editoriais: 48–80px.

Mobile:

section spacing: 80–140px.

Não preencher espaços apenas por medo de “vazio”.

Espaço negativo faz parte da linguagem.

8. Logo

Nome:

LUMUS

A palavra deve ser tratada de maneira tipográfica.

Não criar ícone genérico de câmera.

Não criar lente.

Não criar obturador.

Não criar monograma desnecessário.

A força da marca deve estar na palavra LUMUS.

9. Preloader

Fundo:

#090909

Centro:

LUMUS

Animação:

opacity 0 → 1;

scale 0.97 → 1;

pequena pausa;

scale 1 → 1.02;

opacity → 0;

revelar hero.

Duração curta.

Sem porcentagem.

Sem spinner.

Sem barras.

10. Hero

Layout

100vw;

100vh;

fotografia edge-to-edge;

overflow hidden.

Fotografias

Hero exclusivamente com eventos de marcas.

Escolher imagens visualmente diferentes:

multidão/ambiente;

detalhe;

pessoa;

produto;

palco;

experiência de marca.

Isso evita monotonia.

Overlay

Se necessário para legibilidade de navegação:

usar overlay preto entre 0.05 e 0.20.

Nunca escurecer excessivamente as fotografias.

Transição

Variar de forma controlada:

fade;

clip;

mask;

subtle scale.

Nenhuma transição deve parecer preset de PowerPoint.

11. Hero UI

Topo esquerdo:

LUMUS

Topo direito:

MENU

Inferior esquerdo ou direito:

01 / 06

Opcional:

SCROLL

Tudo discreto.

Cor se adapta conforme contraste da fotografia.

12. Cursor

Desktop opcional.

Cursor pequeno e minimalista.

Em imagens clicáveis:

pode crescer e mostrar:

VIEW

ou

OPEN

Não utilizar cursor gigante.

Mobile:

cursor personalizado desativado.

13. Manifesto

Composição assimétrica.

Texto grande pode ocupar 8–10 colunas.

Evitar centralização.

Uma palavra ou linha pode usar serif italic.

Movimento:

reveal por linha;

translateY sutil;

opacity;

stagger delicado.

Nunca animar letra por letra exageradamente.

14. Selected Stories

Não utilizar cards tradicionais.

Cada projeto deve parecer uma página de revista.

Exemplo:

imagem grande

01

BRAND EXPERIENCE

Maison No. 7 Launch

São Paulo — 2026

Os projetos podem alternar alinhamento.

Projeto 1:
imagem esquerda.

Projeto 2:
imagem direita.

Projeto 3:
imagem fullscreen.

Projeto 4:
duas imagens.

Projeto 5:
imagem vertical.

O layout deve mudar mantendo consistência.

15. Hover de projetos

Desktop:

ao passar sobre título:

fotografia reage levemente;

scale máximo aproximado: 1.025;

metadata pode mudar opacity;

cursor mostra VIEW.

Não criar glow.

Não criar borda neon.

16. Gallery

Composição editorial.

Misturar:

16:9;

4:5;

3:2;

2:3;

full-width.

Nunca cortar todas as imagens no mesmo formato.

17. Horizontal gallery

Desktop:

wrapper pinado;

scroll vertical → movimento horizontal;

velocidade proporcional;

imagens de alturas diferentes;

gaps amplos.

O início/fim da animação deve ser suave.

Mobile:

desativar pin horizontal.

Transformar em galeria vertical.

18. Cinematic section

Background preto.

Começa com fotografia pequena/média centralizada.

Durante scroll:

scale;

transform;

expansão;

troca de frame/imagem;

fundo permanece preto.

Ao final:

texto grande com apenas três palavras.

Exemplo:

Presence.
Energy.
Memory.

Tipografia editorial branca.

19. Events Index

Mostrar:

01 — Brand Events
02 — Festivals
03 — Concerts
04 — Weddings
05 — Fifteen

Brand Events recebe maior escala ou destaque.

Interação desktop:

hover de cada linha pode alterar imagem de preview.

Não transformar categorias em cards.

20. The Lumus Approach

Layout dividido.

Esquerda:

número + texto.

Direita:

imagem.

Ao mudar etapa:

imagem troca;

texto antigo sai;

texto novo entra.

ScrollTrigger pode fixar a imagem enquanto os textos percorrem a tela.

21. About

Fotografia de bastidor grande.

Texto curto.

Não criar:

timeline;

badges;

cards de estatística;

counters;

ícones de câmera.

Manter humano e editorial.

22. CTA final

Imagem fullscreen.

Overlay muito sutil.

Texto grande com bastante respiro.

Botão não deve parecer botão SaaS.

Preferência:

texto-link com seta.

Exemplo:

Tell us about your event ↗

Hover:

linha cresce ou seta desloca poucos pixels.

23. Menu fullscreen

Background preto.

Logo pequena.

Links grandes.

Layout:

01  Stories
02  Brand Events
03  Studio
04  Contact

Hover:

texto muda opacity;

uma fotografia aparece ao fundo;

pequena transição de escala.

A fotografia nunca deve prejudicar leitura.

24. Animações

Biblioteca principal:

GSAP + ScrollTrigger.

Regras

Animações devem ser:

lentas;

fluidas;

intencionais;

ligadas ao conteúdo;

naturais.

Evitar:

bounce;

elastic;

spins;

rotações aleatórias;

objetos flutuando sem sentido;

texto voando;

parallax exagerado;

zoom agressivo.

Ease sugeridas:

power2.out;

power3.out;

expo.out;

custom cubic-bezier quando necessário.

25. Movimento de imagens

Escala máxima comum:

1.02–1.06.

Translate:

moderado.

Parallax:

leve.

A fotografia não deve parecer “efeito”.

Ela deve parecer viva.

26. Mobile

Mobile não é uma versão comprimida do desktop.

Adaptar animações.

Remover ou simplificar:

pinning excessivo;

horizontal scroll;

cursores;

efeitos que dependem de hover;

animações longas demais.

Preservar:

ritmo;

escala;

fotografia;

transições;

tipografia editorial.

Hero continua fullscreen.

27. Reduced Motion

Respeitar:

prefers-reduced-motion

Nestes casos:

remover autoplay agressivo;

substituir scroll animations complexas por fades simples;

reduzir parallax;

manter conteúdo acessível.

28. Coisas proibidas

NÃO criar:

glassmorphism;

blobs;

gradientes coloridos;

glow;

neon;

ícones genéricos;

cards SaaS;

caixas arredondadas sem motivo;

sombras grandes;

fundos com partículas;

elementos 3D decorativos;

linhas aleatórias;

grids com todas as fotos iguais;

sliders tradicionais;

testimonials em cards;

seção “nossos diferenciais” com ícones;

números animados;

estatísticas inventadas;

logos fictícios de clientes;

estrelas de avaliação;

elementos que tirem protagonismo da fotografia.

29. Regra visual final

Antes de adicionar qualquer elemento, perguntar:

isso melhora a fotografia ou compete com ela?

Se competir, remover.

A identidade visual da Lumus é construída por:

photography × typography × space × motion.
